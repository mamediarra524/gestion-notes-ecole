# Note d'utilisation de l'intelligence artificielle

## Présentation

Dans le cadre du développement du projet "Gestion des notes et bulletins d'une école", l'intelligence artificielle a été utilisée comme un outil d'assistance au développement.

L'utilisation de l'IA a permis d'améliorer la productivité tout en conservant une validation humaine des choix techniques et du code produit.

---

# Utilisations de l'IA

L'intelligence artificielle a été utilisée pour :

## Analyse et conception

- aider à organiser l'architecture du projet ;
- réfléchir au modèle de données ;
- vérifier les relations entre les entités ;
- proposer des améliorations techniques.

## Développement Backend

L'IA a aidé à :

- comprendre certaines fonctionnalités Laravel ;
- corriger des erreurs PHP ;
- améliorer des contrôleurs API ;
- vérifier les relations Eloquent ;
- résoudre des problèmes liés à PostgreSQL.

## Développement Frontend

L'IA a aidé à :

- corriger des erreurs Angular ;
- améliorer les composants ;
- structurer les services HTTP ;
- résoudre des problèmes d'affichage et de gestion d'état.

## Débogage

L'IA a été utilisée comme support pour :

- analyser les messages d'erreur ;
- identifier les causes des problèmes ;
- proposer des solutions.

---

# Validation des propositions

Toutes les propositions fournies par l'intelligence artificielle ont été :

- analysées ;
- adaptées au contexte du projet ;
- testées dans l'environnement réel.

Les fonctionnalités finales ont été vérifiées par des tests manuels avec :

- Laravel ;
- Angular ;
- PostgreSQL ;
- Docker.

---

# Limites de l'utilisation de l'IA

L'intelligence artificielle n'a pas remplacé le développement du projet.

Les choix finaux concernant :

- l'architecture ;
- la base de données ;
- les règles métier ;
- l'organisation du code ;
- les tests ;

ont été réalisés et validés dans le cadre du développement du projet.

---

# Conclusion

L'intelligence artificielle a été utilisée comme un assistant technique permettant de gagner du temps, de mieux comprendre certaines notions et de résoudre plus rapidement certains problèmes.

Le projet final reste le résultat d'un travail de conception, d'intégration, de développement et de validation.
