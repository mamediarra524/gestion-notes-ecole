# Note d'utilisation de l'intelligence artificielle

## Présentation

Dans le cadre du développement du projet **"Gestion des notes et bulletins d'une école"**, l'intelligence artificielle a été utilisée comme un outil d'assistance au développement.

L'objectif de cette utilisation était d'améliorer la productivité, de faciliter la compréhension de certaines technologies et d'aider à résoudre des problèmes techniques rencontrés pendant le développement.

L'intelligence artificielle n'a pas remplacé le travail de conception et de développement. Toutes les propositions ont été analysées, adaptées au contexte du projet et validées par des tests dans l'environnement réel.


---

# Utilisations de l'IA


## Analyse et conception

L'intelligence artificielle a été utilisée pour :

- aider à organiser l'architecture générale du projet ;
- réfléchir au découpage frontend / backend ;
- vérifier la cohérence du modèle de données ;
- analyser les relations entre les entités ;
- proposer des améliorations concernant la structure du projet.


## Développement Backend

L'IA a aidé à :

- comprendre certaines fonctionnalités du framework Laravel ;
- expliquer le fonctionnement des modèles Eloquent ;
- corriger certaines erreurs PHP et Laravel ;
- améliorer la structure de certains contrôleurs API ;
- vérifier les relations entre les modèles ;
- résoudre des problèmes liés à PostgreSQL ;
- aider au débogage des routes et de l'authentification Laravel Sanctum.


## Développement Frontend

L'IA a aidé à :

- corriger certaines erreurs Angular ;
- améliorer l'organisation des composants ;
- structurer les services HTTP ;
- expliquer l'utilisation des formulaires Angular ;
- résoudre des problèmes d'affichage ;
- améliorer la communication entre Angular et l'API Laravel.


## Docker et environnement

L'IA a été utilisée pour :

- comprendre la configuration Docker Compose ;
- vérifier la communication entre les conteneurs ;
- résoudre des problèmes de connexion PostgreSQL ;
- améliorer la procédure d'installation du projet.


## Documentation du projet

L'IA a aidé à :

- structurer le fichier README.md ;
- vérifier la conformité avec les consignes du projet ;
- améliorer la présentation de l'architecture ;
- préparer les éléments nécessaires au rendu final.


---

# Exemples de demandes faites à l'IA

Les demandes adressées à l'intelligence artificielle concernaient notamment :

- comment organiser une application Full Stack avec Laravel et Angular ;
- comment corriger des erreurs rencontrées pendant le développement ;
- comment créer et utiliser des relations Eloquent ;
- comment améliorer les contrôleurs et les API REST ;
- comment corriger des composants Angular ;
- comment préparer la documentation GitHub ;
- comment vérifier la conformité du projet avec les critères d'évaluation.


---

# Validation des propositions

Toutes les propositions fournies par l'intelligence artificielle ont été :

- analysées ;
- comprises ;
- adaptées au contexte du projet ;
- testées dans l'environnement réel.

Les fonctionnalités finales ont été vérifiées avec :

- Laravel ;
- Angular ;
- PostgreSQL ;
- Docker.

Les choix techniques finaux ont été réalisés après vérification du fonctionnement de l'application.

# Travail réalisé personnellement

Les éléments suivants ont été réalisés dans le cadre du développement du projet :

- la conception générale de l'application ;
- l'organisation de l'architecture du projet ;
- la configuration Docker Compose ;
- la création de la base de données PostgreSQL ;
- la création des migrations Laravel ;
- la création des modèles Laravel ;
- le développement des contrôleurs API ;
- la mise en place de l'authentification avec Laravel Sanctum ;
- le développement des services Angular ;
- la création des composants Angular ;
- la réalisation de l'interface utilisateur ;

- les tests fonctionnels ;

# Limites de l'utilisation de l'IA

L'intelligence artificielle n'a pas remplacé le développement du projet.

Les décisions finales concernant :

- l'architecture ;
- le modèle de données ;
- les règles métier ;
- l'organisation du code ;
- les choix techniques ;
- les tests réalisés ;

ont été définies, vérifiées et validées pendant le développement.


---

# Conclusion

L'intelligence artificielle a été utilisée comme un assistant technique permettant de gagner du temps, d'améliorer la compréhension de certaines notions et de faciliter la résolution de problèmes.

Elle a contribué à accompagner le développement du projet, mais l'ensemble du travail final résulte d'une démarche personnelle de conception, d'intégration, de développement et de validation.

Le projet final respecte les objectifs demandés et reste le résultat d'un travail réalisé, testé et maîtrisé.
